# Test recordings

Synthetic audio for manually exercising the full pipeline: login → upload → worker
processing → point appears on `/projects/map`. Not real bioacoustic recordings — each
file is a short sine tone + light noise, generated by a one-off script (not checked in;
ask to regenerate if you need a different count/spread), just enough for
`librosa`/Perch v2 to decode and run without special-casing "fake" audio anywhere in the
API or worker.

8 sites scattered ~1-2km apart around Zealandia Ecosanctuary, Wellington — close enough
together to look like one project's recorder network on the map, spread across the last
few days so `recordedAt` sorting/filtering has something to show too.

Upload each through **Your Projects → pick a project → Upload**, pasting the matching
lat/lon below. The recording-time field is a browser `datetime-local` input (local time,
no seconds) — the exact instant doesn't matter for testing, any nearby time is fine.

`manifest.json` has the same data machine-readable (exact ISO timestamps as generated,
`durationSeconds` per clip) if you'd rather script the upload than click through the UI
eight times.

After uploading a few, open **Map** on that project — pins should appear at these
coordinates once each job's status flips to `complete` (check `docker compose logs -f
worker` in `API/` if one seems stuck), and clustering kicks in when you zoom out since
all 8 sites sit close together. Switch to **Detection Heatmap** to see density build up
across the uploaded set (scores are Perch's raw uncalibrated output against real bird
classes — since the audio itself is synthetic tones, whatever species it top-5s are
meaningless, only useful for confirming the plumbing/visualization works end-to-end).
